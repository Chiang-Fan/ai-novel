# 部署方案优化说明

## 🎯 优化目标

将基于 `.env` 环境变量的配置方案，优化为使用 Spring Boot 标准的外部配置文件方案。

## 📊 方案对比

### 旧方案：使用 .env 文件

**配置文件：** `.env`
```bash
QWEN_API_KEY=sk-xxxxx
DB_HOST=localhost
DB_PORT=3306
DB_NAME=ai_novel_writer
DB_USER=root
DB_PASSWORD=xxxxx
SERVER_PORT=8080
```

**启动方式：**
```bash
source .env
sudo nohup java -DDB_HOST=$DB_HOST -DDB_PORT=$DB_PORT ... -jar app.jar
```

❌ **缺点：**
- 配置分散在 `.env` 和启动脚本中
- Spring Boot 不原生支持 `.env`
- 需要额外的脚本处理环境变量
- `sudo` 执行时环境变量容易丢失
- 配置格式简单，不支持复杂结构
- 不便于版本控制和团队协作

---

### 新方案：使用外部 application-prod.yml ⭐

**配置文件：** `application-prod.yml`
```yaml
spring:
  datasource:
    driver-class-name: com.mysql.cj.jdbc.Driver
    url: jdbc:mysql://localhost:3306/ai_novel_writer?...
    username: root
    password: your_password
    hikari:
      maximum-pool-size: 20
  
  ai:
    openai:
      api-key: sk-your-key

ai:
  qianwen:
    api-key: sk-your-key

server:
  port: 8080
```

**启动方式：**
```bash
java -Dspring.config.location=file:application-prod.yml -jar app.jar
```

✅ **优点：**
1. **Spring Boot 原生支持** - 无需额外处理
2. **配置集中管理** - 所有配置在一个文件中
3. **YAML 格式** - 层次清晰，支持复杂结构
4. **修改无需重新打包** - 直接编辑配置文件即可
5. **无 sudo 环境变量问题** - 配置通过文件加载
6. **更好的可读性** - 注释和文档更友好
7. **便于版本控制** - 可以有多个环境的配置文件

## 📦 新部署包结构

```
ai-novel-writer-server/
├── ai-novel-writer.jar          # 应用程序 (84MB)
├── application-prod.yml         # ⭐ 生产环境配置（核心）
├── schema.sql                   # 数据库初始化SQL
├── start-server.sh              # 启动脚本

```

**对比旧版：**
- ❌ 移除：`.env.server` 文件
- ✅ 新增：`application-prod.yml` 外部配置文件
- ✅ 优化：启动脚本更简洁，无需处理环境变量
- ✅ 优化：数据库初始化脚本自动读取配置

## 🚀 部署流程对比

### 旧流程

```bash
1. 解压部署包
2. cp .env.server .env
3. vi .env                        # 修改多个环境变量
4. source .env                    # 加载环境变量
5. ./init-database.sh
6. ./start-server.sh              # 脚本内部处理环境变量传递
```

### 新流程 ⭐

```bash
1. 解压部署包
2. vi application-prod.yml        # 只修改一个文件
3. ./init-database.sh             # 自动从配置文件读取
4. ./start-server.sh              # 自动加载配置文件
```

更简单、更直观！

## 🔧 技术实现

### 1. Spring Boot 配置加载

**启动参数：**
```bash
java -Dspring.config.location=file:application-prod.yml -jar app.jar
```

**加载顺序：**
1. JAR 包内的 `application.yml`（基础配置）
2. 外部的 `application-prod.yml`（覆盖配置）
3. 命令行参数（最高优先级）

### 2. 数据库初始化脚本优化

**自动解析 YAML 配置：**
```bash
# 从 application-prod.yml 提取配置
DB_HOST=$(grep -A10 "datasource:" "$CONFIG_FILE" | grep "url:" | sed ...)
DB_PORT=$(grep -A10 "datasource:" "$CONFIG_FILE" | grep "url:" | sed ...)
DB_USER=$(grep "username:" "$CONFIG_FILE" | awk '{print $2}')
DB_PASSWORD=$(grep "password:" "$CONFIG_FILE" | awk '{print $2}')
```

### 3. 启动脚本优化

**无需环境变量传递：**
```bash
# 旧方式：需要显式传递每个环境变量
sudo nohup java -DDB_HOST=$DB_HOST -DDB_PORT=$DB_PORT ... -jar app.jar

# 新方式：只需指定配置文件
nohup java -Dspring.config.location=file:application-prod.yml -jar app.jar
```

**去除 sudo（如果不需要）：**
- 8080 端口不需要 root 权限
- 避免了环境变量丢失问题
- 更安全

## 📝 配置文件示例

### application-prod.yml

```yaml
# 生产环境外部配置文件
# 将此文件放在 JAR 包同级目录，Spring Boot 会自动加载

spring:
  # 数据源配置 - MySQL
  datasource:
    driver-class-name: com.mysql.cj.jdbc.Driver
    url: jdbc:mysql://localhost:3306/ai_novel_writer?useUnicode=true&characterEncoding=utf8mb4&useSSL=false&serverTimezone=Asia/Shanghai
    username: root
    password: your_mysql_password_here  # ⭐ 修改这里
    hikari:
      maximum-pool-size: 20
      minimum-idle: 5
      connection-timeout: 30000

  # JPA配置
  jpa:
    database-platform: org.hibernate.dialect.MySQLDialect
    show-sql: false
    hibernate:
      ddl-auto: update                  # update/validate/none

  # Spring AI配置 - 通义千问
  ai:
    openai:
      api-key: sk-your-qwen-api-key     # ⭐ 修改这里
      base-url: https://dashscope.aliyuncs.com/compatible-mode/v1

# AI服务配置
ai:
  qianwen:
    api-key: sk-your-qwen-api-key       # ⭐ 修改这里
    model: qwen-plus
    temperature: 0.7

# 服务器配置
server:
  port: 8080

# 日志配置
logging:
  level:
    root: INFO
    com.aiwriter: INFO
  file:
    name: logs/application.log
```

## 🎯 迁移指南

### 对于已部署的旧版本

1. **备份当前配置**
   ```bash
   cp .env .env.backup
   ```

2. **创建新配置文件**
   ```bash
   vi application-prod.yml
   ```
   
   将 `.env` 中的配置迁移到 `application-prod.yml`：
   
   ```
   .env 中的                      application-prod.yml 中的
   ─────────────────────────────────────────────────────────
   QWEN_API_KEY                → spring.ai.openai.api-key
                               → ai.qianwen.api-key
   
   DB_HOST, DB_PORT, DB_NAME   → spring.datasource.url
   DB_USER                     → spring.datasource.username
   DB_PASSWORD                 → spring.datasource.password
   
   SERVER_PORT                 → server.port
   ```

3. **更新启动脚本**
   ```bash
   cp start-server-v2.sh start-server.sh
   ```

4. **重启服务**
   ```bash
   ./restart-server.sh
   ```
