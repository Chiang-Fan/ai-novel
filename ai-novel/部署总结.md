## 🚀 快速部署步骤

### 1. 上传到服务器

```bash
scp ai-novel-writer-server-20251229-201317.tar.gz your_user@your_server:/opt/
```

### 2. 解压

```bash
ssh your_user@your_server
cd /opt
tar -xzf ai-novel-writer-server-20251229-201317.tar.gz
cd ai-novel-writer-server
```

### 3. 配置 application-prod.yml

```bash
vi application-prod.yml
```

**必须修改的 3 处配置：**

```yaml
spring:
  datasource:
    password: your_mysql_password_here        # 1️⃣ MySQL密码
  
  ai:
    openai:
      api-key: sk-your-qwen-api-key-here      # 2️⃣ 通义千问API密钥

ai:
  qianwen:
    api-key: sk-your-qwen-api-key-here        # 3️⃣ 通义千问API密钥
```

### 4. 初始化数据库

```bash
./init-database.sh
```

验证创建了 15 个表：
- novels, chapters, users
- characters, scenes, outlines
- edit_history, character_relationships
- world_settings, plot_threads
- content_analyses, continuation_suggestions
- outline_nodes

### 5. 启动服务

```bash
./start-server.sh
```

成功后访问：
- 📚 前端页面: http://your_server_ip:8080
- 📖 API文档: http://your_server_ip:8080/docs
- 🔍 健康检查: http://your_server_ip:8080/actuator/health

## 📝 配置说明

### Spring Boot 配置加载原理

```
启动命令：java -Dspring.config.location=file:application-prod.yml -jar app.jar

配置加载顺序（后者覆盖前者）：
1. JAR 内的 application.yml           (基础配置，H2数据库)
2. JAR 内的 application-prod.yml      (生产环境默认配置)
3. 外部的 application-prod.yml        ⭐ (实际使用的配置)
4. 命令行参数 -Dkey=value             (最高优先级)
```

### 为什么不使用 .env？

| 对比项 | .env 方案 | YAML 方案 ⭐ |
|--------|-----------|--------------|
| Spring Boot 支持 | ❌ 需脚本处理 | ✅ 原生支持 |
| 配置集中度 | ❌ 分散 | ✅ 集中 |
| sudo 兼容 | ❌ 有问题 | ✅ 无问题 |
| YAML 层次 | ❌ 不支持 | ✅ 支持 |
| 修改便利 | ⚠️ 需source | ✅ 直接生效 |

## ⚠️ 注意事项

### 1. 系统要求

- ✅ JDK 17 或更高版本：`java -version`
- ✅ MySQL 5.7+ 或 8.0+
- ✅ 2GB+ 可用内存
- ✅ 500MB+ 磁盘空间

### 2. 安全配置

```bash
# 设置配置文件权限（保护密码和密钥）
chmod 600 application-prod.yml

# 设置脚本执行权限
chmod +x *.sh
```

### 3. 防火墙配置

```bash
# Ubuntu/Debian
sudo ufw allow 8080/tcp

# CentOS/RHEL
sudo firewall-cmd --permanent --add-port=8080/tcp
sudo firewall-cmd --reload
```

### 4. 数据库字符集

必须使用 `utf8mb4` 字符集：

```sql
CREATE DATABASE ai_novel_writer 
CHARACTER SET utf8mb4 
COLLATE utf8mb4_unicode_ci;
```

### 5. 首次部署建议

```yaml
spring:
  jpa:
    hibernate:
      ddl-auto: update    # 首次部署，自动创建/更新表
```

稳定运行后改为：

```yaml
spring:
  jpa:
    hibernate:
      ddl-auto: validate  # 只验证，不修改表结构
```
