### 数据库设计
```sql
-- 角色关系表
CREATE TABLE character_relationships (
    id BIGINT AUTO_INCREMENT PRIMARY KEY,
    character_id BIGINT NOT NULL,
    related_character_id BIGINT NOT NULL,
    relationship_type VARCHAR(50) NOT NULL,
    description TEXT,
    strength INT DEFAULT 0,
    created_at TIMESTAMP,
    updated_at TIMESTAMP,
    UNIQUE KEY uk_relationship (character_id, related_character_id)
);

-- 角色关系历史表
CREATE TABLE relationship_history (
    id BIGINT AUTO_INCREMENT PRIMARY KEY,
    relationship_id BIGINT NOT NULL,
    change_type VARCHAR(50) NOT NULL,
    old_strength INT,
    new_strength INT,
    old_type VARCHAR(50),
    new_type VARCHAR(50),
    event_desc TEXT,
    related_chapter_id BIGINT,
    change_time TIMESTAMP
);
```

## 🔧 核心算法

### 角色重要性计算
```java
基础分数: 50分

角色类型加分:
- PROTAGONIST (主角): +50分
- ANTAGONIST (反派): +40分
- SUPPORTING (配角): +20分
- MINOR (次要): +10分

重要性等级加分:
- importanceLevel * 2 (最多+20分)

全局主角:
- isGlobalProtagonist: +20分

最终分数 = min(总分, 100)
```

## 📝 使用指南

### 访问关系图谱
1. 进入小说详情页面
2. 点击"角色关系图谱"入口
3. 查看关系网络图

### 添加关系
1. 点击"添加关系"按钮
2. 选择两个角色
3. 选择关系类型和强度
4. 填写关系描述
5. 保存

### 查看演变历史
1. 切换到"关系演变"标签页
2. 选择要查看的关系
3. 查看强度趋势图和历史事件
4. 可添加新事件记录关系变化

1. 在关系列表中找到目标关系
2. 点击编辑按钮修改信息
3. 点击删除按钮移除关系
4. 点击"查看演变历史"查看详情
