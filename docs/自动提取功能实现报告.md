# 自动提取功能实现报告

## 🎯 功能概述

已成功实现章节保存后自动提取元数据的功能，包括：
1. ✅ 自动提取文风特征
2. ✅ 自动识别场景
3. ✅ 自动生成大纲
4. ✅ 自动识别伏笔
5. ✅ 后台异步执行
6. ✅ 可配置相似度阈值

## 📦 新增文件

### 1. 配置类
- `AutoExtractionConfig.java` - 自动提取配置（相似度阈值、功能开关）
- `AsyncConfig.java` - 异步任务配置（线程池）

### 2. 核心服务
- `AutoExtractionService.java` - 自动提取总入口
- `WritingStyleExtractionService.java` - 文风提取服务
- `SceneExtractionService.java` - 场景识别服务
- `OutlineExtractionService.java` - 大纲生成服务
- `PlotHookExtractionService.java` - 伏笔识别服务

### 3. 配置文件
- `application-auto-extraction.yml` - 功能配置

## 🔄 工作流程

```
用户保存章节
     ↓
ChapterService.createChapter() / updateChapter()
     ↓
触发 autoExtractionService.extractAllFromChapter()
     ↓
异步线程池执行
     ↓
并行调用4个提取服务
     ├── WritingStyleExtractionService
     ├── SceneExtractionService
     ├── OutlineExtractionService
     └── PlotHookExtractionService
     ↓
每个服务：
  1. 调用AI识别
  2. 与已有数据比对相似度
  3. 相似度 >= 阈值 → 更新已有记录
  4. 相似度 < 阈值 → 创建新记录
```

## ⚙️ 配置说明

```yaml
ai-writer:
  auto-extraction:
    enabled: true  # 总开关
    
    similarity:
      scene: 0.75         # 场景相似度阈值
      outline: 0.70       # 大纲相似度阈值
      plot-hook: 0.80     # 伏笔相似度阈值
      writing-style: 0.85 # 文风相似度阈值
    
    features:
      extract-writing-style: true
      extract-scene: true
      extract-outline: true
      extract-plot-hook: true
```

## 🔍 相似度判断算法

### 文风相似度
- 比较：句子长度、语气、语言复杂度
- 匹配度计算：matches / total

### 场景相似度
- 比较：名称包含关系（权重2）、位置、类型
- 阈值：0.75（可配置）

### 大纲相似度
- 比较：标题包含关系（权重2）、节点类型
- 阈值：0.70（可配置）

### 伏笔相似度
- 比较：标题包含关系（权重2）、伏笔类型
- 仅比对未解决的伏笔
- 阈值：0.80（可配置）

## 🚀 性能优化

1. **异步执行** - 不阻塞主流程
2. **专用线程池** - 核心2线程，最大4线程
3. **限制AI输入** - 文本截取前1500-2000字
4. **静默失败** - 提取失败不影响章节保存

## 🎯 使用示例

### 前端（无需改动）
用户正常保存章节，系统自动提取：

```javascript
// 用户保存章节
await api.chapters.create({
  novelId: 1,
  content: "章节内容..."
})

// 后台自动：
// 1. AI分析文风 → 同步到文风管理
// 2. AI识别场景 → 同步到场景库
// 3. AI生成大纲 → 同步到大纲树
// 4. AI识别伏笔 → 同步到伏笔管理

```

```java
// ChapterService.java
@Transactional
public Chapter createChapter(ChapterCreateRequest request) {
    // ... 创建章节
    Chapter saved = chapterRepository.save(chapter);
    
    // 🔥 触发自动提取（异步执行）

```

## ⚠️ 注意事项

1. **AI Token消耗** - 每章节约消耗1000-2000 tokens
2. **执行时间** - 通常3-8秒（不阻塞用户）
3. **相似度阈值** - 建议初期设置较高（0.75-0.85），避免误判
4. **功能开关** - 可单独关闭某项功能以节省Token
