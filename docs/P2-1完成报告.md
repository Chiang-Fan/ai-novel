## 🗄️ **数据库表结构**

### 表 1: character_growth_records
```sql
- id (主键)
- character_id (角色ID，外键)
- chapter_id (章节ID，外键)
- record_time (记录时间)
- attributes (属性快照，JSON)
- notes (备注)
- created_at (创建时间)

索引:
- idx_character_id
- idx_chapter_id  
- idx_record_time
```

### 表 2: character_milestones
```sql
- id (主键)
- character_id (角色ID，外键)
- chapter_id (章节ID，外键)
- milestone_type (类型)
- event_name (事件名称)
- description (描述)
- impact_level (影响程度)
- affected_attributes (影响属性，JSON)
- created_at (创建时间)

索引:
- idx_character_id_milestones
- idx_chapter_id_milestones
- idx_milestone_type
```

## 🔧 **核心算法**

### 趋势计算算法
```java
变化 > 1.0  → RISING（上升）
变化 < -1.0 → FALLING（下降）
其他        → STABLE（稳定）
```

### 属性对比算法
```java
change = value2 - value1
changeRate = (change / value1) * 100
```

### AI 分析流程
```
1. 收集角色信息
2. 整理成长趋势
3. 汇总里程碑事件
4. 构建分析提示词
5. 调用 AI 生成建议
6. 解析 AI 返回
7. 结构化输出
```
