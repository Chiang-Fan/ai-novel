# AI智能推荐功能实现报告

## 功能概述

为角色、场景、大纲三大模块添加了AI智能推荐功能，可根据已有数据智能推荐新内容，如无数据则基于书名随机推荐。

## 实现内容

### 一、后端实现

#### 1. 数据传输对象（DTO）

**请求DTO：**
- `CharacterRecommendationRequest.java` - 角色推荐请求
  - novelId: 小说ID
  - count: 推荐数量（默认3个）

- `SceneRecommendationRequest.java` - 场景推荐请求
  - novelId: 小说ID
  - count: 推荐数量（默认3个）

- `OutlineRecommendationRequest.java` - 大纲推荐请求
  - novelId: 小说ID
  - parentId: 父节点ID（可选）
  - nodeType: 节点类型（ARC/VOLUME/CHAPTER/SECTION）
  - count: 推荐数量（默认3个）

**响应DTO：**
- `CharacterRecommendationResponse.java` - 包含角色完整信息
- `SceneRecommendationResponse.java` - 包含场景完整信息
- `OutlineRecommendationResponse.java` - 包含大纲节点完整信息

#### 2. 服务层实现

**CharacterService.java**
- `recommendCharacters()` - AI角色推荐
  - 分析小说类型、已有角色
  - 调用AI生成符合设定的新角色
  - 包含性格、背景、外貌、能力等详细信息
  - 自动设置重要性级别和主角标识

**SceneService.java**
- `recommendScenes()` - AI场景推荐
  - 结合小说类型、已有角色和场景
  - 生成富有画面感的场景描述
  - 包含氛围、天气、道具等细节
  - 确保场景多样化

**OutlineService.java**
- `recommendOutlines()` - AI大纲推荐
  - 分析已有大纲结构和情节进展
  - 推荐合理的下一步剧情
  - 包含关键事件、情节点、主题标签
  - 支持层级结构（父子节点）

#### 3. AI提示词设计

**角色推荐提示词特点：**
- 强调角色层级关系（整体主角、配角、次要）
- 要求详细的性格、背景、外貌描述（100-150字）
- 自动评估重要性级别（1-10）
- 确保与已有角色形成互补或冲突关系

**场景推荐提示词特点：**
- 要求详细的视觉、听觉、嗅觉描述（150字以上）
- 强调氛围和情绪基调（80字以上）
- 列出重要道具列表
- 适合角色活动和情节展开

**大纲推荐提示词特点：**
- 分析已有大纲的逻辑连贯性
- 推荐包含冲突、转折、高潮的情节
- 提供关键事件和情节点列表
- 符合小说类型的典型叙事结构

#### 4. Controller接口

新增推荐接口：
- `POST /api/characters/recommend` - 角色推荐
- `POST /api/scenes/recommend` - 场景推荐
- `POST /api/outlines/recommend` - 大纲推荐

### 三、技术亮点

#### 1. 智能上下文分析

**有数据时：**
- 分析已有内容的类型、风格、角色关系
- 推荐与现有内容互补的新元素
- 保持整体一致性和连贯性

**无数据时：**
- 基于书名和类型进行推断
- 提供符合类型特点的初始内容
- 帮助作者快速启动创作

#### 2. 降级策略

当AI调用失败时：
- 返回预设的随机推荐内容
- 保证功能可用性
- 提示用户为待定内容，需手动完善

#### 3. 数据结构优化

- JSON数组字段自动转换（props、keyEvents等）
- 前端computed属性实现双向绑定
- 友好的表单输入体验（每行一个/逗号分隔）

#### 4. 安全性考虑

**SQL注入防护：**
- 所有推荐请求使用参数化查询
- Service层仅查询数据，不拼接SQL
- DTO验证确保数据合法性

### 四、使用流程

#### 角色推荐

1. 进入角色管理页面，点击"创建角色"
2. 点击对话框头部的"✨ AI智能推荐"按钮
3. 等待3-5秒，系统展示3个推荐角色
4. 浏览推荐卡片，点击喜欢的角色
5. 表单自动填充，可手动修改后保存

#### 场景推荐

1. 进入场景管理页面，点击"创建场景"
2. 点击对话框头部的"✨ AI智能推荐"按钮
3. 系统展示3个推荐场景
4. 点击应用，一键填充表单

#### 大纲推荐

1. 进入大纲编辑页面，点击"添加节点"
2. （可选）先选择节点类型
3. 点击"✨ AI智能推荐"按钮
4. 系统基于已有大纲推荐后续情节
5. 点击应用，完成快速规划
