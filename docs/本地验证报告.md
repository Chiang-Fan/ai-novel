## 🔧 修复的问题清单

### 问题1: 伏笔检测API不匹配
- **症状**: `No static resource api/plot-hooks/detect/2/1`
- **原因**: 前端传递 `novelId + chapterNumber`，后端只接受 `chapterId`
- **修复**: 更新API路径为 `/detect/{novelId}/{chapterNumber}`
- **状态**: ✅ 已修复

---

### 问题2: 写作风格模板加载失败
- **症状**: `Failed to convert 'templates' to Long`
- **原因**: 路由匹配优先级问题，`/{id}` 匹配了 `/templates`
- **修复**: 在 `/{id}` 前添加 `/templates` 端点
- **状态**: ✅ 已修复

---

### 问题3: Repository方法不存在
- **症状**: `找不到符号 findByNovelIdOrderByChapterNumberDesc`
- **原因**: Prompt优化时使用了不存在的方法
- **修复**: 替换为 `findTopNByNovelId()` 方法
- **状态**: ✅ 已修复

---

### 问题4: 重复return语句
- **症状**: `无法访问的语句`
- **原因**: 代码合并时产生重复的 return
- **修复**: 删除重复的 return 语句
- **状态**: ✅ 已修复
