## 🎯 功能详情

### 1. 风格分析系统

#### 自动特征提取
- **语言复杂度**: SIMPLE / MEDIUM / COMPLEX
- **句子长度**: SHORT / MEDIUM / LONG
- **语调风格**: FORMAL / CASUAL / POETIC / HUMOROUS / SERIOUS
- **统计分析**:
  - 平均句长
  - 平均段长
  - 词频分析

#### 风格检测
- AI智能匹配最相似风格
- 置信度评分 (0-100)
- 详细特征报告

### 2. 风格转换引擎

#### 支持的风格分类
- **CLASSIC** - 古典文学
- **MODERN** - 现代文学
- **FANTASY** - 奇幻小说
- **SCIFI** - 科幻小说
- **MYSTERY** - 悬疑推理
- **ROMANCE** - 言情小说

#### 转换流程
1. 分析源文本风格（可选）
2. 选择目标风格
3. AI进行风格转换
4. 计算匹配度评分
5. 生成转换说明

#### 转换特性
- 保持核心内容不变
- 采用目标风格语言特点
- 模仿示例文本表达方式
- 提供多版本选择

### 3. 风格库管理

#### 风格属性
- 名称和作者
- 详细描述
- 示例文本
- 风格特征（JSON格式）
- 分类标签
- 使用统计
- 评分系统

#### 系统预设风格
- 金庸武侠风格
- 鲁迅文学风格
- 现代网文风格
- 西方奇幻风格
- ...（可扩展）

#### 自定义风格
- 用户可创建风格
- 上传示例文本
- 标注风格特征
- 分享给社区

### 4. 转换历史管理

#### 记录信息
- 源文本和转换文本
- 源风格和目标风格
- 转换说明
- 匹配度评分
- 版本号
- 评分反馈

#### 历史功能
- 查看所有转换记录
- 版本对比
- 应用到章节
- 评分和反馈

## 🏗️ 技术架构

### 数据库设计

#### writing_styles (风格库表)
```sql
- id: 主键
- name: 风格名称
- author: 作者/来源
- description: 风格描述
- sample_text: 示例文本
- style_features: 风格特征(JSON)
- category: 分类
- language_complexity: 语言复杂度
- sentence_length: 句子长度
- tone: 语调
- usage_count: 使用次数
- rating: 平均评分
- is_system: 是否系统风格
- created_by: 创建者ID
- created_at: 创建时间
- updated_at: 更新时间
```

#### style_conversions (风格转换记录表)
```sql
- id: 主键
- chapter_id: 章节ID
- source_text: 原文
- converted_text: 转换后文本
- source_style_id: 源风格ID
- target_style_id: 目标风格ID
- conversion_notes: 转换说明
- style_match_score: 匹配度(0-100)
- prompt_used: AI提示词
- ai_model: AI模型
- version: 版本号
- rating: 评分(1-5)
- is_applied: 是否已应用
- applied_at: 应用时间
- created_at: 创建时间
```

#### style_analysis (风格分析结果表)
```sql
- id: 主键
- chapter_id: 章节ID
- text_sample: 分析文本
- detected_style_id: 检测到的风格ID
- analysis_result: 分析结果(JSON)
- confidence_score: 置信度(0-100)
- created_at: 创建时间
```

### 后端结构

#### 实体层 (Entity)
- `WritingStyle` - 写作风格
- `StyleConversion` - 风格转换记录
- `StyleAnalysis` - 风格分析结果

#### 数据访问层 (Repository)
- `WritingStyleRepository`

- `StyleAnalysisRepository`

#### 数据传输层 (DTO)

- `StyleTransferService` - 核心服务
  - `analyzeStyle()` - 风格分析
  - `convertStyle()` - 风格转换
  - `getAllStyles()` - 获取风格库
  - `getConversionHistory()` - 转换历史
  - `applyConversion()` - 应用转换
  - `rateConversion()` - 评分

#### 控制器层 (Controller)
- `StyleTransferController` - API接口

## 📡 API接口

### 1. POST /api/style/analyze
分析文本风格

**参数**:
- chapterId: 章节ID
- text: 文本内容

**响应**:
```json
{
  "id": 1,
  "chapterId": 1,
  "textSample": "...",
  "detectedStyle": {
    "id": 1,
    "name": "金庸武侠",
    "author": "金庸",
    "category": "CLASSIC",
    "matchScore": 85
  },
  "features": {
    "languageComplexity": "MEDIUM",
    "sentenceLength": "MEDIUM",
    "tone": "SERIOUS",
    "avgSentenceLength": 35,
    "avgParagraphLength": 150,
    "description": "..."
  },
  "confidenceScore": 85,
  "createdAt": "2025-12-30T16:00:00"
}
```

### 2. POST /api/style/convert
转换文本风格

**请求体**:
```json
{
  "chapterId": 1,
  "text": "原始文本",
  "targetStyleId": 2,
  "analyzeSource": true,
  "maxVersions": 3
}
```

**响应**:
```json
{
  "id": 1,
  "chapterId": 1,
  "sourceText": "...",
  "convertedText": "...",
  "sourceStyle": {
    "id": 1,
    "name": "现代网文",
    "category": "MODERN"
  },
  "targetStyle": {
    "id": 2,
    "name": "古典文学",
    "category": "CLASSIC"
  },
  "conversionNotes": "...",
  "styleMatchScore": 88,
  "version": 1,
  "rating": null,
  "isApplied": false
}
```

### 3. GET /api/style/styles
获取风格库

**参数**:
- category: 分类 (可选)

### 4. GET /api/style/history/{chapterId}
获取转换历史

### 5. POST /api/style/{conversionId}/apply
应用转换

### 6. POST /api/style/{conversionId}/rate
评分

**参数**:
- rating: 评分 (1-5)

## 💡 核心算法

### 1. 风格特征提取
```java
private StyleFeatures extractStyleFeatures(String text) {
    - 计算平均句长
    - 计算平均段长
    - 判断语言复杂度
    - 判断句子长度风格
    - 词频统计分析
    - 生成特征描述
}
```

### 2. 风格相似度匹配
```java
private WritingStyle findMostSimilarStyle(StyleFeatures features) {
    - 遍历风格库
    - 计算特征相似度
    - 加权评分
    - 返回最匹配风格
}
```

### 3. 转换提示词构建
```java
private String buildConversionPrompt(String text, WritingStyle targetStyle) {
    - 说明转换目标
    - 提供原文
    - 描述目标风格特点
    - 展示示例文本
    - 列出转换要求
}
```

### 4. 匹配度评分
```java
private int calculateStyleMatch(String text, WritingStyle style) {
    - 提取转换文本特征
    - 与目标风格对比
    - 计算相似度分数
    - 返回0-100分值
}
```
