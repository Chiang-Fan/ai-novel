## 🎯 功能特性

### 1. 后台静默执行
- 使用 `@Async` 注解
- 专用线程池（2-4线程）
- 不阻塞用户写作

### 2. 智能相似度判断
- 场景相似度：0.75（比较名称、位置、类型）
- 大纲相似度：0.70（比较标题、节点类型）
- 伏笔相似度：0.80（比较标题、伏笔类型）
- 文风相似度：0.85（比较句长、语气、复杂度）

### 3. 配置化管理
```yaml
ai-writer:
  auto-extraction:
    enabled: true
    similarity:
      scene: 0.75
      outline: 0.70
      plot-hook: 0.80
      writing-style: 0.85
    features:
      extract-writing-style: true
      extract-scene: true
      extract-outline: true
      extract-plot-hook: true
```

## 📊 工作流程

```
用户保存章节
    ↓
ChapterService保存成功
    ↓
触发 AutoExtractionService.extractAllFromChapter()
    ↓
异步线程池执行（不阻塞）
    ↓
并行调用4个AI提取服务
    ├── 文风特征 → 相似度匹配 → 更新/创建
    ├── 场景信息 → 相似度匹配 → 更新/创建
    ├── 大纲结构 → 相似度匹配 → 更新/创建
    └── 伏笔元素 → 相似度匹配 → 更新/创建
    ↓
静默完成（3-8秒）
```
