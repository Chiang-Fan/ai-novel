## 🚀 功能特性

### 1. **自动触发机制**
- ✅ **新增章节时**：`ChapterService.createChapter()` → 触发自动提取
- ✅ **更新章节内容时**：`ChapterService.updateChapter()` → 检测内容变化 → 触发提取
- ✅ **异步执行**：使用专用线程池 `autoExtractionExecutor`，不阻塞用户操作

### 2. **智能相似度匹配**

| 提取类型 | 阈值 | 匹配逻辑 | 更新/创建 |
|---------|------|---------|---------|
| 文风 | 0.85 | 特征字符串匹配 | 使用次数+1 / 新建记录 |
| 场景 | 0.75 | 场景名称匹配 | 记录notes / 新建场景 |
| 大纲 | 0.70 | 标题+内容匹配 | 标记完成 / 新建节点 |
| 伏笔 | 0.80 | 标题+描述匹配 | 状态→HINTED / 新建伏笔 |

### 3. **配置化管理**

```yaml
# application-auto-extraction.yml
ai-writer:
  auto-extraction:
    enabled: true  # 总开关
    similarity:
      writing-style: 0.85
      scene: 0.75
      outline: 0.70
      plot-hook: 0.80
    features:
      extract-writing-style: true
      extract-scene: true
      extract-outline: true
      extract-plot-hook: true
```

**修改配置即可调整行为，无需改代码！**

## ⚙️ 异步执行配置

### 线程池参数

```java
@Configuration
@EnableAsync
public class AsyncConfig {
    @Bean("autoExtractionExecutor")
    public Executor autoExtractionExecutor() {
        ThreadPoolTaskExecutor executor = new ThreadPoolTaskExecutor();
        executor.setCorePoolSize(2);        // 核心线程
        executor.setMaxPoolSize(4);         // 最大线程
        executor.setQueueCapacity(100);     // 队列容量
        executor.setThreadNamePrefix("auto-extract-");
        executor.setRejectedExecutionHandler(new ThreadPoolExecutor.CallerRunsPolicy());
        executor.initialize();
        return executor;
    }
}
```

## 🐛 修复的问题

### 1. 章节分析选择器为空

**问题**：API拦截器已解包`response.data`，但前端仍访问`.data`

```javascript
// ❌ 错误
const response = await api.chapters.list(novelId)
chapters.value = response.data  // data是undefined

// ✅ 修复
const data = await api.chapters.list(novelId)
chapters.value = data || []
```

### 2. 伏笔检测API参数不匹配

**问题**：前端调用 `/plot-hooks/detect/2/1`，后端只有 `/{chapterId}`

// ✅ 修复
