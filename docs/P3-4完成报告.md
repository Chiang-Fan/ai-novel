## 🎯 功能详情

### 1. 智能建议生成 (5种类型)

#### PLOT_TWIST - 情节转折
- 分析当前情节走向
- 建议转折时机
- 评估影响力

#### CONFLICT_ESCALATION - 冲突升级
- 识别现有冲突
- 建议升级方案
- 强度评估

#### CHARACTER_ARC - 角色弧光
- 分析角色发展
- 建议成长路径
- 关联角色

#### FORESHADOWING - 伏笔处理
- 检测未解决伏笔
- 建议展开时机
- 关联伏笔ID

#### PACING - 节奏调整
- 分析叙事节奏
- 建议调整方案
- 章节分布

### 2. 情节推演系统

#### 推演类型
- **SHORT_TERM** - 短期推演 (1-3章)
- **MEDIUM_TERM** - 中期推演 (4-10章)
- **LONG_TERM** - 长期推演 (10+章)

#### 推演内容
- 情节发展预测
- 关键事件提取
- 角色变化分析
- 情节线追踪

#### 推演特性
- AI智能分析
- 置信度评分 (0-100)
- 多版本对比
- 采纳机制

### 3. 冲突追踪管理

#### 冲突类型
- **INTERNAL** - 内心冲突
- **INTERPERSONAL** - 人际冲突
- **SOCIAL** - 社会冲突
- **NATURAL** - 自然冲突
- **SUPERNATURAL** - 超自然冲突

#### 冲突状态
- **BUILDING** - 酝酿中
- **ACTIVE** - 进行中
- **CLIMAX** - 高潮
- **RESOLVED** - 已解决

#### 冲突属性
- 强度等级 (0-100)
- 涉及角色
- 引入章节
- 升级节点
- 解决方式

### 4. 建议管理

#### 优先级系统
- **URGENT** - 紧急
- **HIGH** - 高优先级
- **MEDIUM** - 中等
- **LOW** - 低优先级

#### 状态流转
```
PENDING → ACCEPTED → APPLIED
        ↘ REJECTED
```

#### 影响力评分
- 0-100分量化
- 关联分析
- 推理依据

## 🏗️ 技术架构

### 数据库设计

#### plot_suggestions (情节建议表)
```sql
- id: 主键
- novel_id: 小说ID
- chapter_id: 关联章节ID
- suggestion_type: 建议类型
- title: 建议标题
- description: 详细描述
- reasoning: 推理依据
- priority: 优先级
- impact_score: 影响力(0-100)
- related_plot_hook_id: 关联伏笔ID
- related_character_id: 关联角色ID
- status: 状态
- applied_chapter_id: 应用章节ID
- applied_at: 应用时间
- created_at: 创建时间
- updated_at: 更新时间
```

#### plot_projections (情节推演表)
```sql
- id: 主键
- novel_id: 小说ID
- current_chapter_id: 当前章节ID
- projection_text: 推演内容
- projection_type: 推演类型
- chapters_ahead: 推演章节数
- confidence_score: 置信度(0-100)
- key_events: 关键事件(JSON)
- character_changes: 角色变化(JSON)
- plot_threads: 情节线(JSON)
- prompt_used: AI提示词
- ai_model: AI模型
- is_adopted: 是否采纳
- adopted_at: 采纳时间
- created_at: 创建时间
```

#### conflict_tracking (冲突追踪表)
```sql
- id: 主键
- novel_id: 小说ID
- conflict_type: 冲突类型
- title: 冲突标题
- description: 冲突描述
- involved_characters: 涉及角色(JSON)
- intensity_level: 强度(0-100)
- introduced_chapter_id: 引入章节ID
- escalation_points: 升级节点(JSON)
- resolution_chapter_id: 解决章节ID
- status: 状态
- resolution_type: 解决方式
- created_at: 创建时间
- updated_at: 更新时间
```

### 1. POST /api/plot/suggestions/generate
生成情节建议

**参数**:
- novelId: 小说ID

**响应**:
```json

  {
    "id": 1,
    "novelId": 1,
    "suggestionType": "FORESHADOWING",
    "title": "建议解决伏笔：神秘宝藏",

```

获取建议列表

**参数**:
- status: 状态过滤 (可选)

### 3. PUT /api/plot/suggestions/{suggestionId}/status
更新建议状态

**参数**:
- status: 新状态 (PENDING/ACCEPTED/REJECTED/APPLIED)
