## 🗄️ **数据库设计**

### 表结构

#### conversation_sessions（会话表）
```sql
字段（11个）:
├─ id (主键)
├─ novel_id (外键 → novels)
├─ chapter_id (外键 → chapters，可选)
├─ session_title (会话标题)
├─ session_type (会话类型)
├─ context_snapshot (上下文快照 JSON)
├─ total_messages (总消息数)
├─ status (状态: ACTIVE/ARCHIVED)
├─ created_at (创建时间)
└─ updated_at (更新时间)

索引（5个）:
- novel_id, chapter_id, status, created_at, updated_at
```

#### conversation_messages（消息表）
```sql
字段（9个）:
├─ id (主键)
├─ session_id (外键 → conversation_sessions)
├─ role (角色: USER/ASSISTANT/SYSTEM)
├─ content (消息内容，LONGTEXT)
├─ message_type (消息类型)
├─ metadata (元数据 JSON)
├─ token_count (Token 数量)
├─ response_time (响应时间 ms)
└─ created_at (创建时间)

索引（3个）:
- session_id, role, created_at
```
