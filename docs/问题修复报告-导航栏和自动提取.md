## 🐛 问题2：文风提取失败（POST method not supported）

### 问题描述
```
响应错误: Request method 'POST' is not supported
```

点击"提取写作风格"按钮时调用了不存在的`POST /api/writing-styles/extract`端点

### 根本原因
前端调用的API端点不存在：
```javascript
// 前端调用
api.post('/writing-styles/extract', { novelId, chapterId })

// 后端没有这个端点
@PostMapping("/extract") // ❌ 不存在
```

### 修复方案

由于我们已经实现了**自动提取功能**（在创建/更新章节时自动执行），手动提取功能已不再必要。

**修改前端UI**：
```vue
<!-- ❌ 修复前：需要手动选择章节并点击提取 -->
<div v-else class="text-center py-12">
  <h3>尚未提取写作风格</h3>
  <p>请先选择一个章节来分析小说的写作风格</p>
  <select v-model="selectedChapterId">...</select>
  <Button @click="extractStyle">提取写作风格</Button>
</div>

<!-- ✅ 修复后：提示自动提取机制 -->
<div v-else class="text-center py-12">
  <h3>尚未提取写作风格</h3>
  <p>系统会在创建或更新章节时自动提取文风特征<br>
     请先创建一些章节内容，文风数据将自动生成</p>
  <Button @click="loadData">刷新数据</Button>
</div>
```

**删除的代码**：
- `extractStyle()` 函数
- `validateContent()` 函数
- `selectedChapterId`、`extracting`、`validating`等状态变量

**修改文件**: `WritingStyleManager.vue`

## 🐛 问题3：AI续写后没有自动提取

### 问题描述
使用AI续写功能创建新章节后，文风、场景、大纲、伏笔等都没有自动提取

### 根本原因
`ChapterService.continueChapter()` 方法中没有调用 `autoExtractionService.extractAllFromChapter()`

### 修复方案

在AI续写后触发自动提取：

```java
// ❌ 修复前
@Transactional
public Chapter continueChapter(ChapterContinueRequest request) {
    ...
    Chapter saved = chapterRepository.save(chapter);
    novelService.updateNovelStats(request.getNovelId());
    autoAnalyzeAfterContinuation(saved);  // 只有分析
    return saved;
}

// ✅ 修复后
@Transactional
public Chapter continueChapter(ChapterContinueRequest request) {
    ...
    Chapter saved = chapterRepository.save(chapter);
    novelService.updateNovelStats(request.getNovelId());
    
    // 🔥 触发自动提取（异步执行）
    autoExtractionService.extractAllFromChapter(saved);
    
    autoAnalyzeAfterContinuation(saved);
    log.info("AI续写完成: chapterId={}, words={}, 已触发自动提取", 
             saved.getId(), wordCount);
    return saved;
}
```

**修改文件**: `ChapterService.java`

## 🎯 功能说明

### 自动提取触发时机

1. **手动创建章节** → `ChapterService.createChapter()` → 自动提取
2. **手动更新章节** → `ChapterService.updateChapter()` → 检测内容变化 → 自动提取
3. **AI续写章节** → `ChapterService.continueChapter()` → 自动提取

### 自动提取内容

- ✅ **文风特征**：句长、语气、复杂度（相似度阈值0.85）
- ✅ **场景识别**：场景名称、类型（相似度阈值0.75）
- ✅ **大纲生成**：章节标题、内容摘要（相似度阈值0.70）
- ✅ **伏笔识别**：关键词检测、伏笔分类（相似度阈值0.80）

### 执行特性

- **异步执行**：专用线程池（2-4线程），不阻塞用户操作
- **静默运行**：后台执行，用户无感知
- **耗时**：3-8秒（取决于内容长度）
- **失败处理**：静默失败，记录日志，不影响主流程
