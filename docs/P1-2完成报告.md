## 🎯 核心功能列表

### 1️⃣ **智能续写生成** 🤖
**API**: `POST /api/continuation/generate`

**功能特性**:
- 📝 支持 3 种长度类型（短/中/长）
- 🎨 支持 4 种文风类型（一致/创意/正式/轻松）
- 🎲 可配置创意温度（0.0-1.0）
- 🎭 可指定情感基调
- 📊 自动提取上下文（500-2000 字）
- 🔢 同时生成 1-3 个方案

**请求示例**:
```json
{
  "chapterId": 1,
  "position": -1,
  "lengthType": "MEDIUM",
  "styleType": "CONSISTENT",
  "variantCount": 2,
  "temperature": 0.7,
  "plotHint": "主角遇到危机",
  "emotionTone": "紧张",
  "contextLength": 1000
}
```

**响应示例**:
```json
{
  "code": 0,
  "message": "成功",
  "data": {
    "batchId": "uuid",
    "variants": [
      {
        "id": 1,
        "content": "续写内容...",
        "wordCount": 523,
        "qualityScore": 0.85,
        "styleConsistency": 0.92,
        "plotCoherence": 0.88,
        "recommendationReason": "这个方案文风稳定，情节连贯"
      }
    ],
    "contextInfo": {
      "contextBefore": "前文内容...",
      "contextLength": 985,
      "currentPlotPoint": "正在发展中",
      "currentEmotion": "平稳"
    }
  }
}
```

## 🗄️ 数据库设计

### `continuation_history` 表

```sql
CREATE TABLE continuation_history (
    id BIGINT AUTO_INCREMENT PRIMARY KEY,
    chapter_id BIGINT NOT NULL,              -- 所属章节
    position INT NOT NULL,                   -- 续写位置
    
    context_before LONGTEXT,                 -- 上下文
    context_length INT,                      -- 上下文长度
    generated_content LONGTEXT NOT NULL,     -- 生成内容
    
    settings TEXT,                           -- 配置JSON
    quality_score DOUBLE,                    -- 质量评分
    style_consistency DOUBLE,                -- 文风一致性
    plot_coherence DOUBLE,                   -- 情节连贯性
    
    accepted BOOLEAN DEFAULT FALSE,          -- 是否采纳
    accepted_at TIMESTAMP,                   -- 采纳时间
    
    variant_number INT DEFAULT 1,            -- 方案编号
    batch_id VARCHAR(50),                    -- 批次ID
    
    feedback TEXT,                           -- 用户反馈
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    
    FOREIGN KEY (chapter_id) REFERENCES chapters(id),
    INDEX idx_chapter_id (chapter_id),
    INDEX idx_batch_id (batch_id),
    INDEX idx_accepted (accepted),
    INDEX idx_created_at (created_at)
);
```

**字段说明**:
- **17 个字段**
- **4 个索引**（chapter_id, batch_id, accepted, created_at）
- **外键约束**（级联删除）

## 📊 智能续写流程

### 生成流程
```
1. 接收请求
   ├─ 提取章节内容
   ├─ 验证参数
   └─ 生成批次ID

2. 上下文分析
   ├─ 提取前文内容
   ├─ 分析情节点
   ├─ 识别活跃角色
   └─ 评估情感基调

3. 文风匹配
   ├─ 查询文风数据
   ├─ 提取叙事视角
   ├─ 提取语言风格
   └─ 提取句式偏好

4. 提示词构建
   ├─ 系统角色
   ├─ 小说信息
   ├─ 章节信息
   ├─ 上下文
   ├─ 文风要求
   ├─ 续写要求
   └─ 质量标准

5. AI 生成
   ├─ 调用 DeepSeek API
   ├─ 循环生成 N 个方案
   └─ 错误处理

6. 质量评估
   ├─ 质量评分（字数、复杂度）
   ├─ 文风一致性（模式匹配）
   └─ 情节连贯性（上下文）

7. 保存记录
   ├─ 保存到数据库
   ├─ 关联批次ID
   └─ 记录配置

8. 返回响应
   ├─ 构建响应对象
   ├─ 包含所有方案
   └─ 附带上下文信息
```

## 🎯 质量评估算法

### 1. 质量评分 (`qualityScore`)
```java
double wordCountScore = Math.min(1.0, wordCount / 500.0);
double complexityScore = 0.8; // 简化版本
qualityScore = (wordCountScore + complexityScore) / 2.0;
```

### 2. 文风一致性 (`styleConsistency`)
```java
// 检查是否包含特定词汇、句式
if (writingStyle != null) {
    if (content.contains(writingStyle.getTone())) score += 0.3;
    if (content.contains(writingStyle.getSentenceStyle())) score += 0.3;
}
styleConsistency = score;
```

### 3. 情节连贯性 (`plotCoherence`)
```java
// 检查是否与上下文连贯
if (contextInfo != null && contextInfo.getCurrentPlotPoint() != null) {
    if (content.contains(contextInfo.getCurrentPlotPoint())) {
        score += 0.3;
    }
}
plotCoherence = score;
```
