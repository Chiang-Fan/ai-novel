#### POLISH - 润色优化

#### GRAMMAR - 语法检查
- 修正语法错误
- 规范标点符号

#### DIALOGUE - 对话优化

## 🏗️ 技术架构

### 数据库设计

#### content_optimizations (内容优化记录表)
```sql
- id: 主键
- chapter_id: 章节ID
- original_text: 原始文本
- optimized_text: 优化后文本
- optimization_type: 优化类型
- changes_summary: 变更摘要(JSON)
- prompt_used: AI提示词
- ai_model: AI模型
- version: 版本号
- rating: 评分(1-5)
- is_applied: 是否已应用
- applied_at: 应用时间
- created_at: 创建时间
```

#### optimization_rules (优化规则表)
```sql
- id: 主键
- name: 规则名称
- rule_type: 规则类型
- pattern: 匹配模式(正则)
- description: 规则描述
- suggestion: 修改建议模板
- severity: 严重程度
- is_enabled: 是否启用
- usage_count: 使用次数
- created_at: 创建时间
- updated_at: 更新时间
```

## 📡 API接口

### 1. POST /api/optimization/optimize
优化文本

**请求体**:
```json
{
  "chapterId": 1,
  "text": "原始文本",
  "optimizationType": "POLISH",
  "includeExplanation": true,
  "maxVersions": 3
}
```

**响应**:
```json
{
  "id": 1,
  "chapterId": 1,
  "originalText": "...",
  "optimizedText": "...",
  "optimizationType": "POLISH",
  "changes": [
    {
      "type": "MODIFY",
      "original": "...",
      "modified": "...",
      "reason": "...",
      "position": 0
    }
  ],
  "version": 1,
  "rating": null,
  "isApplied": false,
  "createdAt": "2025-12-30T16:00:00"
}
```

### 2. POST /api/optimization/check
检查文本质量

**参数**:
- text: 文本内容
- chapterId: 章节ID (可选)

**响应**:
```json
{
  "totalIssues": 5,
  "issues": [
    {
      "type": "GRAMMAR",
      "severity": "HIGH",
      "message": "...",
      "suggestion": "...",
      "startPosition": 10,
      "endPosition": 20,
      "affectedText": "..."
    }
  ],
  "qualityScore": {
    "overall": 85,
    "grammar": 90,
    "style": 80,
    "readability": 85,
    "consistency": 88
  }
}
```

### 3. GET /api/optimization/history/{chapterId}
获取优化历史

**参数**:
- optimizationType: 优化类型 (可选)

### 4. POST /api/optimization/{optimizationId}/apply
应用优化到章节

### 5. POST /api/optimization/{optimizationId}/rate
评分优化结果

**参数**:
- rating: 评分 (1-5)

### 6. GET /api/optimization/rules
获取优化规则

**参数**:
- ruleType: 规则类型 (可选)

## 🔄 工作流程

### 优化流程
1. 用户选择需要优化的文本
2. 选择优化类型（润色/语法/对话/描写/节奏）
3. AI根据类型生成优化版本
4. 展示变更对比
5. 用户评分并决定是否应用

### 检查流程
1. 输入文本内容
2. 系统应用所有启用的规则
3. 识别各类问题（语法/风格/一致性/冗余）
4. 计算质量分数
5. 展示问题列表和修改建议
