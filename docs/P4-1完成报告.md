## 📊 数据库设计

### 新增表：3个

#### 1. `generated_images` - AI生成图片表
```sql
- id: 主键
- novel_id: 所属小说
- chapter_id/character_id/scene_id: 关联对象
- image_type: 图片类型
- prompt/negative_prompt: 提示词
- style: 绘画风格
- image_url/local_path: 存储路径
- width/height/file_size: 图片参数
- quality_score: 质量评分
- is_adopted: 是否采用
- tags: 标签数组
```

#### 2. `image_generation_history` - 生成历史表
```sql
- id: 主键
- novel_id: 所属小说
- prompt/style: 生成参数
- batch_size: 批次数量
- generated_count/success_count: 统计
- cost: 成本
- duration_seconds: 耗时
```

#### 3. `image_templates` - 图片模板表
```sql
- id: 主键
- name/category: 名称和分类
- prompt_template: 提示词模板
- negative_prompt_template: 负面提示词
- default_style: 默认风格
- recommended_size: 推荐尺寸
- usage_count: 使用次数
- is_system: 是否系统模板
```

**字段总数**: 47个  
**索引总数**: 11个

## 📈 功能流程

### 生成流程
```
1. 接收请求
   ↓
2. 加载模板（可选）
   ↓
3. 构建完整提示词（角色/场景信息+风格+质量）
   ↓
4. 调用AI服务生成
   ↓
5. 保存结果（URL+本地路径）
   ↓
6. 记录历史
   ↓
7. 更新模板使用统计
```

### 查询流程
```
按小说ID → 按类型过滤 → 按时间排序 → 返回列表
按章节ID → 章节专属图片
按角色ID → 角色形象图
按场景ID → 场景氛围图
```

## 🎨 使用场景示例

### 场景1: 生成角色形象图
```json
{
  "novelId": 1,
  "characterId": 5,
  "imageType": "CHARACTER",
  "style": "ANIME",
  "batchSize": 4,
  "width": 768,
  "height": 1024
}
```
→ 自动读取角色名称和外貌描述生成4张动漫风格角色图

### 场景2: 生成场景氛围图
```json
{
  "novelId": 1,
  "sceneId": 12,
  "imageType": "SCENE",
  "style": "WATERCOLOR",
  "templateId": 3,
  "prompt": "sunset, golden hour"
}
```
→ 使用模板+场景描述+自定义提示词生成水彩风格场景图

### 场景3: 生成小说封面
```json
{
  "novelId": 1,
  "imageType": "COVER",
  "style": "OIL_PAINTING",
  "prompt": "epic fantasy world, dramatic lighting",
  "width": 1024,
  "height": 1536
}
```
→ 生成古典油画风格的史诗级封面
