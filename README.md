## 🎯 系统简介

### 📖 这是什么？
AI智能小说创作系统是一个**专业的小说写作工具**，它能够：
- 🤖 **AI智能续写** - 根据您的故事自动生成后续章节
- 💡 **智能建议** - 为您推荐场景、大纲、情节发展方向
- 📋 **结构管理** - 帮您规划长篇小说的场景和大纲
- 👥 **角色管理** - 记录人物关系，保持角色一致性
- 📚 **历史记录** - 支持撤销重做，不怕写错

### 🎨 适合谁使用？
- ✅ **新手作者** - 不知道如何开始写小说
- ✅ **经验作者** - 想要提高创作效率
- ✅ **长篇作者** - 需要管理复杂的故事结构
- ✅ **兼职作者** - 时间有限，需要AI辅助

## 🚀 快速开始（5分钟上手）

### 第一步：启动系统 ⚡

#### 方法一：一键启动（推荐）
```bash
# 1. 打开终端（命令行）
# Windows: 按 Win+R，输入 cmd，回车
# Mac: 按 Cmd+空格，输入 terminal，回车

# 2. 进入项目文件夹
cd ai-write-agent

# 3. 运行启动脚本
./start.sh
```

#### 方法二：手动启动
```bash
# 1. 启动后端服务
source venv/bin/activate  # Mac/Linux
# 或
venv\Scripts\activate     # Windows

uvicorn app.main:app --host 0.0.0.0 --port 8000 --reload

# 2. 新开一个终端，启动前端
cd frontend
npm start
```

### 第二步：访问系统 🌐
启动成功后，在浏览器中打开：
- **主界面**：http://localhost:3000
- **API文档**：http://localhost:8000/docs

> 💡 **提示**：如果页面打不开，请检查终端是否有错误信息

## 📝 创建您的第一部小说

### 1️⃣ 新建小说项目

1. **打开主页面**
   - 在浏览器访问 http://localhost:3000
   - 您会看到小说列表页面

2. **点击"创建新小说"按钮**
   - 位于页面右上角的蓝色按钮
   - 会弹出创建表单

3. **填写小说基本信息**
   ```
   📖 小说标题：例如"穿越异世界的冒险"
   📝 简介：简单描述故事背景和主要情节
   🎭 类型：选择小说类型（玄幻、都市、科幻等）
   👥 目标读者：选择读者群体（青少年、成人等）
   ✍️ 写作风格：选择您喜欢的风格（轻松、严肃、幽默等）
   ```

4. **点击"创建"按钮**
   - 系统会自动保存您的小说项目
   - 创建成功后会跳转到小说详情页

> 💡 **新手提示**：不用担心填错，所有信息后续都可以修改

### 2️⃣ 规划小说结构

#### 📋 创建大纲（推荐先做）

1. **进入大纲视图**
   - 在小说详情页点击"大纲视图"标签
   - 您会看到一个树形结构的大纲编辑器

2. **创建根节点**
   - 点击"创建根节点"按钮
   - 填写节点信息：
     ```
     📝 标题：例如"第一卷：初入异世界"
     📄 内容：详细描述这一卷的主要内容
     🏷️ 类型：选择节点类型（卷、章、节等）
     ```

3. **创建子节点**
   - 点击已有节点旁的"+"按钮
   - 可以创建多层级的大纲结构
   - 例如：卷 → 章 → 节 → 场景

4. **使用AI建议**
   - 在创建节点时，点击"✨ 获取AI建议"
   - AI会根据您的小说背景推荐5个大纲节点
   - 选择喜欢的建议，一键应用到表单

> 💡 **规划技巧**：建议先规划3-5个大的章节，每个章节下再细分场景

#### 🎬 创建场景

1. **进入场景管理**
   - 在小说详情页点击"场景管理"标签
   - 您会看到场景卡片网格布局

2. **创建新场景**
   - 点击"创建新场景"按钮
   - 填写场景信息：
     ```
     🎬 场景标题：例如"主角初到异世界"
     📝 场景描述：详细描述场景内容和发生的事件
     🌅 氛围设定：选择场景氛围（紧张、轻松、神秘等）
     ⚔️ 主要冲突：描述这个场景的主要矛盾或冲突点
     📋 关键事件：列出场景中的重要事件
     ```

3. **使用AI场景推荐**
   - 点击"✨ 获取AI建议"按钮
   - AI会推荐3个适合的场景
   - 每个建议包含完整的场景设定

4. **管理场景状态**
   - 📝 **规划中**：刚创建的场景
   - ✍️ **写作中**：正在创作的场景
   - ✅ **已完成**：写完的场景

> 💡 **场景技巧**：每个场景建议控制在1-3个章节的内容量

## ✍️ 开始AI续写

### 3️⃣ 创作第一个章节

1. **进入续写页面**
   - 在小说详情页点击"AI续写"标签
   - 或者从场景卡片点击"开始写作"

2. **选择写作场景**
   - 在页面顶部的下拉框中选择场景
   - 系统会显示场景的详细信息
   - AI会根据场景设定来续写内容

3. **填写续写信息**
   ```
   📖 章节标题：例如"第一章：异世界的第一天"
   📝 当前内容：输入您已经写好的内容（可以为空）
   🎯 续写要求：告诉AI您希望写什么
   例如："描述主角刚到异世界时的震撼和困惑"
   📊 目标字数：建议1000-3000字
   ```

4. **获取AI建议**（可选）
   - 点击"✨ 情节建议"按钮
   - AI会推荐5个不同的情节发展方向
   - 选择喜欢的方向，自动填入续写要求

5. **开始续写**
   - 点击"开始续写"按钮
   - AI会根据您的要求生成内容
   - 通常需要5-15秒，请耐心等待

6. **查看和编辑结果**
   - AI生成的内容会显示在结果区域
   - 您可以直接编辑修改内容
   - 满意后点击"保存章节"

> 💡 **续写技巧**：
> - 第一次续写建议从简单的场景开始
> - 续写要求要具体明确，避免太模糊
> - 可以多次续写，逐步完善章节

### 4️⃣ 继续后续章节

1. **查看已有章节**
   - 在小说详情页可以看到所有章节列表
   - 点击章节标题可以查看详细内容

2. **续写下一章**
   - 点击"继续写作"或"AI续写"
   - 系统会自动加载前面的章节作为上下文
   - AI会保持故事的连贯性

3. **管理写作进度**
   - 场景卡片会显示写作进度
   - 完成场景后可以标记为"已完成"
   - 系统会自动统计字数和章节数

## 👥 角色管理

### 5️⃣ 创建和管理角色

1. **进入角色管理**
   - 在小说详情页点击"角色管理"标签
   - 您会看到角色列表和详细信息

2. **创建新角色**
   - 点击"添加角色"按钮
   - 填写角色信息：
     ```
     👤 姓名：角色的名字
     📝 描述：角色的基本介绍
     🎭 性格：详细的性格特征
     📚 背景：角色的成长经历和背景故事
     ⭐ 重要程度：1-5星，主角通常是5星
     👀 外貌：详细的外貌描述
     ```

3. **使用AI角色关系建议**
   - 在角色管理页面点击"✨ 获取关系建议"
   - AI会推荐新的角色关系
   - 帮助您构建丰富的人物关系网

4. **角色关系管理**
   - 可以设定角色之间的关系
   - 支持多种关系类型（朋友、敌人、恋人等）
   - AI续写时会考虑这些关系

> 💡 **角色技巧**：
> - 主要角色要详细设定，次要角色可以简单一些
> - 定期更新角色信息，特别是性格发展
> - 利用AI建议来丰富角色关系

## 💡 写作技巧和最佳实践

### ✍️ 高效创作流程

1. **规划阶段**
   ```
   第1步：确定小说基本设定（类型、风格、目标读者）
   第2步：创建主要角色（主角、配角、反派）
   第3步：规划大纲结构（卷、章、主要情节点）
   第4步：设计关键场景（开头、转折点、高潮、结局）
   ```

2. **创作阶段**
   ```
   第1步：选择当前要写的场景
   第2步：回顾相关角色和前情
   第3步：明确这一章的目标和冲突
   第4步：使用AI续写，获得初稿
   第5步：编辑修改，完善细节
   ```

3. **完善阶段**
   ```
   第1步：检查情节连贯性
   第2步：确认角色行为一致性
   第3步：优化语言表达
   第4步：调整章节结构
   ```

### 🎯 AI续写技巧

#### 📝 如何写好续写要求

**✅ 好的续写要求示例：**
```
"在这一章中，主角李明发现了古老遗迹的入口。请描述他内心的震撼和犹豫，以及最终决定进入的过程。重点刻画遗迹的神秘氛围和主角的心理变化。字数控制在2000字左右。"
```

**❌ 不好的续写要求示例：**
```
"继续写下去"
"写点有趣的内容"
"让故事更精彩"
```

#### 🎨 续写要求的关键要素

1. **具体情节**：明确这一章要发生什么
2. **角色行为**：说明主要角色要做什么
3. **情感基调**：指定章节的情感氛围
4. **重点内容**：强调需要详细描写的部分
5. **字数要求**：给出大概的字数范围

#### 🔄 多次续写策略

1. **分段续写**
   - 不要一次性续写太长
   - 建议每次1000-3000字
   - 可以分多次完成一个章节

2. **迭代改进**
   - 第一次续写获得基本框架
   - 第二次续写补充细节
   - 第三次续写优化语言

3. **场景切换**
   - 不同场景分别续写
   - 保持场景内的一致性
   - 注意场景间的过渡

### 🎭 角色塑造技巧

#### 👤 角色设定要点

1. **基本信息**
   ```
   姓名：简洁有特色
   年龄：符合故事设定
   职业：与情节相关
   外貌：有特色但不过分
   ```

2. **性格特征**
   ```
   核心特质：2-3个主要性格特点
   优点缺点：平衡设置，避免完美人设
   说话方式：独特的语言习惯
   行为模式：典型的行为反应
   ```

3. **背景故事**
   ```
   成长经历：影响性格形成的关键事件
   人际关系：与其他角色的关系网络
   目标动机：角色的追求和恐惧
   变化弧线：角色在故事中的成长
   ```

#### 🔗 角色关系设计

1. **主要关系类型**
   - 👫 **盟友关系**：共同目标，相互支持
   - ⚔️ **对立关系**：冲突矛盾，推动情节
   - 💕 **情感关系**：爱情、友情、亲情
   - 🎭 **复杂关系**：亦敌亦友，多重身份

2. **关系发展规律**
   - 初识阶段：建立第一印象
   - 了解阶段：逐渐深入认识
   - 冲突阶段：暴露矛盾和分歧
   - 和解阶段：解决问题，关系升华

### 📋 大纲规划技巧

#### 🏗️ 结构层次设计

1. **三幕结构**
   ```
   第一幕（25%）：设定背景，引入角色，提出问题
   第二幕（50%）：发展冲突，推进情节，角色成长
   第三幕（25%）：解决冲突，达成目标，故事结局
   ```

2. **章节规划**
   ```
   每章目标：明确每章要达成的目标
   冲突设置：每章都要有小冲突或进展
   悬念设置：章末留下悬念，吸引读者
   节奏控制：张弛有度，避免平铺直叙
   ```

3. **情节线管理**
   ```
   主线情节：核心故事线，贯穿全文
   支线情节：辅助故事线，丰富内容
   伏笔设置：提前埋下线索
   回收伏笔：适时揭示答案
   ```

## 🚨 常见问题解答

### 🔧 技术问题

#### Q1: 系统启动失败怎么办？
**A:** 按以下步骤检查：
1. **检查Python环境**
   ```bash
   python --version  # 需要3.8或更高版本
   ```
2. **检查依赖安装**
   ```bash
   pip install -r requirements.txt
   ```
3. **重新初始化数据库**
   ```bash
   python app/init_db.py
   ```
4. **查看错误日志**
   ```bash
   cat backend.log  # 查看详细错误信息
   ```

#### Q2: AI续写没有反应？
**A:** 可能的原因和解决方法：
1. **检查API密钥配置**
   - 确认.env文件中的DASHSCOPE_API_KEY是否正确
   - 确认API密钥是否有效且有余额

2. **检查网络连接**
   - 确认能够访问通义千问API服务
   - 尝试重新启动后端服务

3. **检查续写要求**
   - 续写要求不能为空
   - 避免使用特殊字符或过长的文本

#### Q3: 前端页面显示异常？
**A:** 尝试以下解决方法：
1. **清除浏览器缓存**
   - 按Ctrl+F5强制刷新页面
   - 或者清除浏览器缓存和Cookie

2. **检查后端连接**
   - 确认后端服务正在运行
   - 访问 http://localhost:8000/docs 检查API

3. **重启前端服务**
   ```bash
   cd frontend
   npm start
   ```

### ✍️ 使用问题

#### Q4: AI生成的内容质量不好？
**A:** 提升AI生成质量的方法：
1. **优化续写要求**
   - 提供更详细、具体的描述
   - 明确指出重点和风格要求
   - 给出合适的字数范围

2. **完善角色设定**
   - 详细设置主要角色的性格和背景
   - 建立清晰的角色关系网络
   - 保持角色设定的一致性

3. **改进上下文**
   - 确保前面章节的质量
   - 保持故事逻辑的连贯性
   - 及时更新角色和情节信息

#### Q5: 如何管理长篇小说的复杂结构？
**A:** 长篇管理的最佳实践：
1. **使用场景分割**
   - 将长篇分解为多个场景
   - 每个场景控制在合适的长度
   - 明确场景间的逻辑关系

2. **建立详细大纲**
   - 使用多层级大纲结构
   - 定期更新和调整大纲
   - 利用AI建议完善大纲

3. **角色档案管理**
   - 为每个重要角色建立详细档案
   - 记录角色的成长和变化
   - 定期检查角色行为一致性

#### Q6: 如何保持写作的连贯性？
**A:** 保持连贯性的技巧：
1. **定期回顾**
   - 写作前回顾前面的章节
   - 检查情节发展的逻辑性
   - 确认角色行为的合理性

2. **使用编辑历史**
   - 利用系统的历史记录功能
   - 对比不同版本的差异
   - 必要时恢复到之前的版本

3. **建立写作笔记**
   - 记录重要的情节点
   - 跟踪伏笔的设置和回收
   - 维护角色关系的变化

#### Q8: 如何备份我的小说数据？
**A:** 数据备份方法：
